HeLa Cellular Ecosystem:
- Cytosol (browser-mcp): Web browser automation, navigation, clicking, typing, page state, scraping, screenshots.
- Nucleus (terminal-mcp): Shell commands, bash execution, terminal sessions, CLI tools, build/test execution.
- Membrane (filesystem-mcp): Filesystem operations, file read/write, directory listing, copy, move, regex search.
- Genome (project-mcp): Persistent knowledge graph, entity/relation memory, session context, SQLite operations.
- Enzyme (researcher-mcp): Web search (zero-key fallback), arXiv academic research, Google News RSS, Wikipedia retrieval, fact-checking.
- Phenotype (designer-mcp): UI/UX design tokens, OKLCH palettes, CSS/Tailwind generation, Awwwards motion, and Stitch Canvas operations.
- Plastid (ll3m-mcp): 3D modeling with Blender, mesh creation, scene inspection, rendering.
- Receptor (scrcpy-mcp): Mobile Android device automation, ADB shell, touch tap/swipe, UI inspection.
- Ribosome (menager-mcp): Process multiplexer, PTY session management, event hooks.
- Mitosis (chaining-mcp): Capability routing, sequential thinking, task planning, and orchestration.
Rule: Always map requests to the organelle that specializes in that domain.
